# Predictive performance and modality attribution in melanoma classification

Code and results for the paper of the same title (Siddika et al.).
Two image–metadata fusion models (concatenation "Fusion" and gated "MetaBlock")
are compared on ISIC-DICM-17K, with PAD-UFES-20 as a secondary check.
